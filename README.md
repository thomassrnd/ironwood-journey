# Ironwood Journey

A fantasy-inspired gym RPG launch menu and app shell built as a fast prototype.

## Quick start

1. Install dependencies:
   `npm install`
2. Start the dev server:
   `npm run dev`
3. Open the local URL shown in the terminal (usually http://localhost:3000)

## Features in this prototype
- Launch screen with a single call-to-action: `Start your journey`
- Smooth light-up transition between the intro and the main menu
- Main menu with three entries: `Saves`, `New Save`, and `Settings`
- Dark fantasy / military aesthetic with a cinematic UI feel

## Notes
This is intentionally a design-and-prototype shell. The next steps will be to add real save data, character creation, workout logging, and full game mechanics.
